#+title: Bounded native POO path-slot declarations

* Entry and boundary

=:yuanxu/object-syntax/path-slots= exports authoring bindings =.def=, =.o= and
=@method= (braces). Import them instead of the corresponding primitive bindings
in a configuration owner. The pinned =:clan/poo/object= bindings are unchanged;
they continue to support literal dotted slot names. There is no runtime patch
interpreter, Loader hook or global syntax replacement.

#+begin_src scheme
(import :yuanxu/object-syntax/path-slots
        (only-in :clan/poo/object .get))

(.def Parent
  module: (.o build: (.o command: '("gerbil" "build"))
               test: (.o command: '("gerbil" "test"))))

(.def (Child @ Parent)
  module.build: =>.+ {command: '("gerbil" "build" "release")}
  module.test: =>.+ {command: '("gerbil" "test" "release")})
#+end_src

The child lowers to one native refinement of module:

#+begin_src scheme
(.def (Child @ Parent)
  module: =>.+
  {build: =>.+ {command: '("gerbil" "build" "release")}
   test: =>.+ {command: '("gerbil" "test" "release")}})
#+end_src

* Expansion law

Paths admit a direct leaf assignment or an explicit native ==>.+= refinement.
Direct assignment replaces the complete leaf value, including an object-valued
leaf; it does not implicitly merge that leaf. Every intermediate path segment
still lowers to native ==>.+=, retaining the inherited intermediate object.
An ordered expansion-time trie
merges shared prefixes, including interleaved roots, and emits one native slot
method per prefix. Work is linear in declarations plus path segments and emitted
syntax, excluding the native expander's own work. No source or payload is
executed during lowering. Native payload expressions retain their syntax and
lexical scope; generated ancestor objects use the native object constructor.

#+begin_src scheme
(.def (Observed @ tests)
  execution.profile.emit?: #t
  execution.environment.TMPDIR: workspace)

;; Equivalent primitive POO expansion, with one shared execution refinement.
(.def (Expanded @ tests)
  execution: =>.+
  (.o profile: =>.+ (.o emit?: #t)
      environment: =>.+ (.o TMPDIR: workspace)))
#+end_src

Explicit =.o= and brace refinement bodies support relative paths. Arbitrary
expressions and quoted data are opaque to the lowering. Native headers, defaults,
shared slots and ordinary methods retain native normalization; object/brace
match patterns delegate to the native matcher. This adapter reserves dotted
slot names for paths; use the primitive binding to author a literal dotted slot.
Leading-dot method names such as =.run=, =.acquire= and =.release= remain ordinary
slots in this entry, so native fixture and execution objects need no aliases.

Duplicate paths, empty segments, unsupported path operators and ancestor/descendant
overlaps in one body fail during expansion. Express an intentional ancestor
refinement and its relative descendant inside that ancestor's object body.
Missing/non-object intermediates fail on native demand; they are not created.

* Receiver and lazy cache evidence

=t/path-slots-test.ss= executes the actual adapter, not only a handwritten
expansion. Its cases include direct leaf assignment with shared prefixes,
inherited intermediate fields, lazy payloads and whole-object leaf replacement,
as well as simultaneous build/test/package/Pipeline
refinement after the parent Pipeline/list are cached, exact child Check identities,
parent cache and sibling isolation, warm-cache identity, a fixed-parent-list stale
negative control, native-expansion parity, aliases/payload hygiene, relative paths,
interleaved prefixes, native syntax/matching, lazy payload demand and diagnostics.

The Pipeline relationship remains a native lexical slot expression:

#+begin_src scheme
pipeline: (.o checks: (list build test package))
#+end_src

No checks synchronization is added. Reading one target does not evaluate a
sibling payload. These source-runtime controls do not establish Loader demand
granularity, native AOT qualification or first-access latency guarantees.

* Field diagnostic provenance

Authoring constructors now retain the original slot token's one-based line and
column on a private native computed-slot specification subtype. Native .+
copies retain the right-hand specification's locator. No public metadata slots
or parallel field registry are added. Diagnostic lookup follows only the
requested object path and checked native precedence; unknown raw-native writes
are not attributed to an older inherited declaration. Default-only clauses
remain native defaults and do not relabel a paired method.

See [[file:../docs/10-19-design/10-configuration/10.17-scheme-field-origins.org][10.17]] and =t/slot-origin-test.ss= for JSON baseline retention,
source-currentness checks, payload laziness, relocated Scenario validation and
the explicit source-package/AOT boundary. This does not add dotted direct
assignment or product Loader integration.
