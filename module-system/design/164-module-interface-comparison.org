* Research purpose

Design a configuration experience that supports both upstream ownership of
thousands of modules/Profiles and downstream progressive disclosure: ordinary
business configuration first, native extension when required. Compare actual
authoring tasks, validation and effective-value semantics rather than ranking
languages by syntax brevity or implementation power.

This research replaces the previous compressed comparison. It uses configuration
languages and their module frameworks as peers. There is no general-purpose
systems-language comparison. No Loader or runtime implementation is added here.

* Findings that change the design

For KCL's documented replacement/insertion/merge distinctions and the associated
POO UX obligations, see [[file:../../docs/10-19-design/11-configuration-languages/11.02-kcl-data-overlays.org][10 KCL and data overlays]]. This official-language
comparison is distinguished from the actual library/ecosystem cases above.

NixOS complexity is partly language/framework layering and partly the real cost
of composing distributed typed definitions. Nickel integrates contracts and
merge metadata, while Jsonnet already supports effective-object inheritance and
Dhall provides a different typed/total trade-off. Those capabilities prevent us
from claiming that POO alone introduces safe composition or late binding.

Agentic AI Lab has a useful demonstrated continuity between configuration objects,
inheritance and Pipeline consumption. Current weaknesses include incomplete
public-attribute admission/discovery, ambiguous front-door terminology, source-role
alignment, fixed Check membership and missing effective-value explanations.
The improvement plan treats each as a concrete design obligation.

The actual [[file:164-funflow-local-publication.org][local Funflow publication]] remains the implementation baseline.
The earlier [[file:164-config-language-case-research.org][case research]] is background; it is not a substitute for the extracted
code, matched semantics and reflection modules in this study.
