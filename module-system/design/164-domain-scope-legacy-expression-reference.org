* Boundary

The old domain helper expansions/direct policy examples below are superseded.
They are migration research, not a recommended alternate user interface. Use
[[file:164-bounded-domain-module-scope-examples.org][the complete bounded module scope examples]] for the current target design.
None is a macro/runtime receipt or implemented domain API.

** LangGraph: Contract initialization and native lowering

*** Contract initialization: name the domain Contract directly

#+begin_src scheme
(.def (FreshLangGraphScenario @ LangGraphCompositionContract)
  Profiles: =>.+
  {production: =>.+
   {graph: (use-module LangGraphModule)}})
#+end_src

Native configured-slot expansion for this fresh value:

#+begin_src scheme
(.def (FreshLangGraphScenario @ (.get LangGraphCompositionContract proto))
  (Profiles => .+
    (.o
      (production (inherited)
        (let ((profile-contract
               (scenario-profile-contract-for LangGraphCompositionContracts 'production)))
          (.+ (inherited)
              (.o graph: (%configured-module
                            profile-contract 'graph LangGraphModule
                            '(session state router agent-node tool-node bounded-loop runtime-handoff)))))))))
#+end_src

The user names the domain Contract; the native expansion obtains its shared
proto. This is proposed contextual parent recognition, not native descriptor
inheritance. Generated Module values use
slot-owned instance names and inherit their concrete responsibility proto plus
the selected domain contributions. Helpers are proposed. Compare the maintained-object path below:
it inherits an already configured Scenario value and preserves owner additions.

*** Native objectification and refinement

* Explicit default binding is optional when the Scenario already owns it

When introducing or rebinding a Module, retain the proposed explicit declaration:

#+begin_src scheme
(.def (MyCrewBinding @ CrewAIScenario)
  Profiles: =>.+
  {production: =>.+
   {crew: (use-module CrewAIModule)}})
#+end_src

The combined crew example can then inherit MyCrewBinding instead of CrewAIScenario.
The analogous graph/tool bindings use their corresponding Modules. This changes
neither the native inline policy refinement nor the responsibility chain.
No-selection use-module and local-slot identity remain proposed contextual
adapters, so they are not disguised as an existing native loader expansion.
