This is the per-binding appendix to [[file:164-core-functional-and-extend-interface-audit.org][the interface audit]].
Baseline Core SHA: =e85fd45303b208b23e5957fd316e7004994109a4=.
D = default Functional; E = Extend; R = explicit runtime/host; M = controlled meta; I = internal.
Classification is an API placement decision, not a blanket proof of purity.
D means eligibility behind a Functional facade, not a requirement for root users to import Core leaves, construct descriptors or use raw slot readers.
The ordinary product entry uses module selection and keyword settings; native construction/inheritance belong in Extend documentation.
D operations require admitted values and the owning behavior contract; arbitrary POO callbacks can still have effects.
Repeated facade/leaf exports are retained as occurrences. =(export #t)= is expanded to current top-level def bindings.
Import reexports link to their owning file sections; tests/build/manifest declarations are excluded.
The source scan covers export declarations, not every private binding or upstream gerbil-poo API.

Coverage: 66 export-bearing source files; 1287 named export occurrences; D 225, E 521, R 68, M 30, I 443.
