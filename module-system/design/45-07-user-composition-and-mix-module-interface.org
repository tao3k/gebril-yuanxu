* Current implementation boundary

The composition-binding macro in the public composition chapter is historical.
Current code uses native =def= and =.new Scenario= from
=:yuanxu/modules/funflow/scenario=. Its Record Contract and private plan
projection share one owner. No compatibility macro or Workflow facade
is published. The module-authoring and evidence arguments below retain
their stated premises; they do not establish the removed syntax as an API.
See [[file:../../dev/sysml/20-module-loading/20.30-test-discovery-and-domain-demand.org][the current ownership and assurance boundary]].

* Status correction

Historical draft.  Its public =use-composition= clause grammar is superseded by
RFC 45-92, RFC 45-95 and RFC 164.  Current code must use runtime noun slots
for object-level algebra and a thin root binding over already composed Profile
values; no compatibility surface is implied.
