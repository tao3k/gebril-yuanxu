* N-way content-aware replica summary

** N-way content-evidence closure requirement

Content-aware replica evidence MUST be closed under repeated join.  A binary
join that carries its left and right obligations but returns only
=ReplicaRegistryCheckpointKnowledge= cannot be used as a content-aware input to
the next join; projecting to the maximum position discards the type-level owner
of the origin dispositions.

A reusable summary MUST retain every committed origin represented by the join,
prove that each origin is no later than the summary position, and carry the
descriptor disposition from every origin to that position.  Joining summaries
MUST union origins, extend all dispositions to the maximum position, and return
the same summary type.

** Pairwise evidence non-closure observation

=ContentAwareReplicaRegistryCheckpointJoinEvidence left right= is a proof about
one pair.  Its only prior output projection,
=positionKnowledgeOfContentAwareReplicaJoin=, returns the old position-only
type.  It therefore cannot represent the three-way expression
=(left join right) join third= without discarding content evidence.

The arithmetic join already had associative, commutative, and idempotent laws;
those theorems covered only =Nat.max=.  They did not prove the same laws for
origin membership or descriptor obligations.

** N-way summary decision

- Add =positionRecoveryValid= to content-aware replica knowledge; a manually
  assembled knowledge value cannot claim a recovery interval without the
  existing validity proof.
- Add =extendDescriptorDispositionAcrossRegistryInterval=.  A disposition at an
  intermediate position extends to any later position by composing governed
  lineage evidence; an earlier retirement remains valid throughout the longer
  interval.
- Define =ContentAwareReplicaRegistryCheckpointSummary= with a minimum position,
  an origin predicate, origin coverage, and per-origin descriptor dispositions.
- Derive the singleton-origin summary canonically from content-aware recovery.
- Define summary join as =Nat.max= plus origin union and disposition extension.
  Its result is the same summary type and is therefore closed under arbitrary
  repeated joins.
- Prove observational associative, commutative, and idempotent laws for both
  positions and origin membership.  Descriptor disposition remains mandatory
  for every member of the resulting origin union.
