* Publication-domain semantic-identity binding

** Publication-domain semantic-identity requirement

A registered checkpoint watermark MUST bind its descriptor to the exact
authoritative publication domain whose validation semantics the verifier will
execute.  Matching only publication-domain identity and authority identity is
insufficient: an independently registered descriptor can retain both values
while substituting a different publication-domain semantic identity.

This identity is the semantic identity of the publication-domain validator.  It
MUST NOT be equated with the Cedar input content semantic identity or with the
registry trust-root semantic identity; those identities have distinct owners.

** Publication-domain semantic-substitution counterexample

=RegisteredCheckpointWatermarkEvidence= previously established descriptor
registration, publication-domain identity equality, and authority equality.  It
did not relate that descriptor to the intended
=AuthoritativeContextPublicationDomain=.  Therefore a descriptor with the same
domain and authority identities but a different =semanticIdentity= could still
form valid registered evidence.

=registeredCheckpointWatermarkPermitsDomainSemanticSubstitution= constructs
that witness using the real checkpoint-watermark structures.  The mismatch is
not a hypothetical parser state: it is inhabited by the existing Lean model.

** Typst model

#+begin_export typst
$
  "DomainBoundWatermark"(e, d) :=
    e."descriptor" = "project-domain-descriptor"(d)

  "DomainBoundWatermark"(e, d)
  implies
  e."descriptor"."semantic-identity" = d."semantic-identity"

  e."descriptor"."domain-id" = d."domain-id"
  and e."descriptor"."authority-id" = d."authority-id"
  and e."descriptor"."semantic-identity" != d."semantic-identity"
  implies not "DomainBoundWatermark"(e, d)
$
#+end_export

** Publication-domain semantic-identity decision

- Preserve =RegisteredCheckpointWatermarkEvidence= as the weaker executable
  model and as the owner of the substitution counterexample.
- Strengthen the existing v1 closure with
  =PublicationDomainBoundRegisteredCheckpointWatermarkEvidence=.  Its
  =descriptorMatchesDomain= field binds the registered descriptor to the exact
  projection of the intended publication domain.
- Derive semantic-identity equality from that object equality.  Do not create a
  V2 compatibility surface and do not conflate the three semantic-identity
  domains.

** Closure checklist

- [X] Distinguish publication-domain, Cedar-content, and registry semantic
  identities by owner.
- [X] Construct same-domain/same-authority semantic substitution using the real
  registered-watermark structures.
- [X] Bind registered evidence to the exact intended publication-domain
  descriptor projection.
- [X] Prove bound evidence preserves publication-domain semantic identity.
- [X] Prove a mismatched semantic identity cannot satisfy the closed evidence.
