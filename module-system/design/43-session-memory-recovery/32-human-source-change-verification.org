* Focused result

[[file:31-controlled-human-source-change.org][The source-change protocol]] passed ten focused Quint Cases: safe authorization,
admission and retention invariants; first replacement, second binding and fresh
consumption reachability; deliberately unsafe unapproved changes, old permits,
old recovery authorization, prebinding decisions, retired-source use and Project
erasure. Negative controls require actual TLC counterexamples, not parser errors.

Thirteen Context Lean roots built in 84 jobs. HumanSourceChange adds ten
theorems/eight guards using LeanPOO Focus: issued/admin/live-target requirements,
captured generation, no-op refusal, successor generation, old proposal refusal,
issuance-cut/foreign-source refusal and retained knowledge. These conditional
pure laws assume truthful identity/currentness projections; they do not prove
remote operator authenticity or the Scheme/OS mutex implementation.

Fresh Scheme replay naturally exited 0 with 288 assertions, 42 source-change
controls added to the prior 246. They consume real ORG-derived Context and
actual Core/Governance/Assurance objects on the existing serialized Host owner.
Controls cover unapproved and forged approvals, copied/same-name sources,
no-op changes, missing preconfiguration/receipts, old captured permits after
retirement, independent authorization after retirement, copied/cross-proposal
and competing permit replay, withdrawn approval, exact source/cut publication,
old recovery authorization/decision, excluded prebinding decisions, fresh decision
acceptance, re-opened owned pending obligations and fresh recovery after rebind.

An actual live switch does not globally retire a shared source or uninstall an
already recovered controller. ABA returns to a still-live source at generation
four; the old permit and a decision issued while that source was unbound remain
unusable. Completed and foreign proposals do not spuriously reopen owned
obligations. Project Context remains present, and effect delivery is never called.
