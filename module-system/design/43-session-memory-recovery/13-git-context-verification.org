* Qualified scope

graphs. This receipt qualifies one finite source-lens Case and conditional Lean
projection, not every isolation mechanism or the full dynamic architecture.

implementation was changed. Observing/staging/committing in the Quint model
does not execute any Git mutation. Source-repository and Artifact-repository
reconciliation, target promotion and real Query adapter remain open.

* Lean result

The current Context proof package built successfully with 75 jobs under the
unchanged 120s bound. The new GitContext root consumes LeanPOO v0.1.1's Focus
API and adds five laws/five guards: edit scope preservation and composition;
Worktree, selected-untracked and Query revision distinctions; Contract revision
is additionally covered by a guard. Current roots total 36 laws / 40 guards.
Scope/content distinction proofs use no axioms; the functional update
composition audit uses =propext=. No new axiom or sorry is introduced.

The finite =Cut= is a proof projection, not the public Query interface or a
second source evaluator. Equality of cuts is not authentication, effective
authorization or a proof of actual Git capture. Previous GraphContext guards
still exercise the real upstream C4 object/resolver; this root does not pretend
to establish C3/C4 laws anew from Git tokens.
