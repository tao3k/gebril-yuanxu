* Owner and scope

[[file:35-recovered-controller-session-handoff.org][35 defines the protocol]]. Modules owns the optional collection-bearing source
proposal and final controller/installation/registry publication. Proofs supplies
actual consumer inputs and observes Modules. This receipt does not supersede the
historical cuts in 32/34, claim remote CI or change storage executors, bindings,
old Memory or effect delivery. RFC 0015 remains an SDLC consumer only.

* Attempts and evidence discipline

The first Lean build failed because a record-update theorem omitted its explicit
=Permit= parameter type. The declaration was corrected and the complete Context
Lean target rebuilt successfully; the failed build is not proof evidence and no
=sorry= was added. The preliminary fresh Scheme replay naturally passed 409
assertions. Additional old pending-controller permit, forged Query and root
revocation-during-handoff controls were then added; that earlier replay does not
qualify the final source cut.

TLC remains 60 seconds total / 12 seconds silence, one worker / 512 MiB. Lean
remains 120 seconds. Scheme remains 120 seconds total / 5 seconds silence and
1 GiB heap; existing worker joins remain two seconds. No forced successful exit,
watchdog bypass or relaxed verification policy is used.

* Reproduction

Use the current installed Scheme package with its existing ASCENT package.
Compile consumer registry, installation, source control, admission and interface
in producer order, then the Assurance adapter and proof consumer. Keep the
declared sources and compiled package pool stable for the complete run. With
=CONTEXT_ASCENT_GERBIL_PATH= set to that existing dependency directory, run from
the repository root:

* Focused formal result

All thirteen focused Quint Cases passed: one safe complete exploration, four
reachability controls (ticket before activation, handoff, fresh admission and
stale pending permit), and eight deliberately unsafe mutations (double
activation, missing activation, old controller, old/consumed source permit,
old Query, old review and knowledge erasure). Negative controls require actual
TLC counterexamples; parser errors/timeouts do not satisfy them.

Fifteen Context Lean roots built in 86 jobs, adding fourteen theorems/nine guards
(140 theorems / 118 guards across Context roots). Printed axioms remain explicit.
These laws assume truthful projections of issued/private identities, current
receipts and atomic publication; they do not prove Scheme locks or remote users.

* Focused Scheme result

The final focused replay naturally exited 0 with 413 assertions, adding 46 to
the preceding 367. Real ORG Elements/Contract-derived Context and actual
Core/Governance/Assurance issuers are consumed on the serialized effect Host
owner. Controls distinguish recovery ticket, activation, source authorization,
collection cut and review rather than simulating them with Boolean issuers.

The old controller's still-unconsumed pending permit, old installation ticket,
copied configuration/permit, recovery receipt used as source approval and a
retargeted copied proposal are refused. A callback changes the old collection
between check/commit; another changes only the target source revision. Both
refuse without advancing the source generation. A target lacking an existing
slice's Session cannot silently drop that slice. Fresh successful handoff is
generation one after those failures and advances the exact registry once.

Old/prebinding sets, Queries and a pending collection proposal become stale.
A copied Query cannot be retargeted, old request/review/Profile cannot revive,
and missing fresh review reopens the obligation. A fresh Profile/review/Query
accepts the same Project Context cut under the new exact Session source.
Replaying consumed or stale-target source permits fails. Revoking the successor
root during a subsequent handoff callback refuses that commit and leaves the
collection unchanged, while admission withdraws and its obligation reopens.
The independently admitted Project view remains admitted both after predecessor
revocation and after successor revocation; Context retention is not merely
asserted by counting a reconstructed list.

executable regressions; and 413 fresh Scheme assertions. The fresh replay adds

lanes are not summed as independent proof obligations. The new safe Quint
exploration completed with 246 generated / 88 distinct states.
