projects the selected Elements after applying the authored Contract. The
consumer checks real node-property ID Query and parent-child topology.

- Removing a consumer or binding an empty collection retains Context identity.
- Duplicate Session IDs, non-Session objects and raw Contract/Query inputs refuse.
- Retrieval alone supplies no use basis; actual-use facts and review are explicit premises.
- Reviewed selection supports a current interpretation, not a grant.
- Time drift reopens transient Context while retaining an applicable stable constraint.

  counterexample history.

a legacy handoff value, not Context ownership, consolidation or storage success.

orchestrator or evidence of message/provider dispatch.
