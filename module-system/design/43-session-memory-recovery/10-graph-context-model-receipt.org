* Actual Lean consumer

[[file:../../../../packages/proofs/lean-poo/AgenticAILabContextLifecycleProof/GraphContext.lean][GraphContext.lean]] imports the actual C3 cache-coherence theorem, C4
VerifiedOrder and Object.Memo/Prototype APIs. Five universal consumer laws:

- Complete C3 cached/reference outcomes agree for the same finite graph/roots.
- Two C4 certificates for the same graph/root have identical outputs.
- Successful C4 output contains no duplicate ancestor names.
- Output membership corresponds to the graph's actual ancestry relation.
- The verified wrapper preserves the checked resolver's exact success/error.

Eight executable guards use those library implementations: shared Project
diamond, conflicting parent orders, missing parent, duplicate node, exact
self-cycle diagnostic, local override/final-self dependency, persistent
revision and child-first order not being a shared prompt prefix.

The override control observes base/branch constraints =2/9= and derived
values =3/10=. It retains the original object but disproves the unconditional
claim that an untouched computed declaration must retain its value. The
revision control retains old =2= while the revised object reads =5=.

=timeout 120s lake build AgenticAILabContextLifecycleProof= passed with 74 build
jobs. All current Context roots together contain 31 declared laws and 35
guards; five laws and eight guards belong to this new consumer. Audited new
laws use only Lean's existing =propext=, =Classical.choice= and =Quot.sound=.
No new axiom, sorry, disabled linter or widened deadline is added. Upstream
unused-simp warnings remain visible.

Initial compilation failed because =Except= had no =BEq= instance for the
guards; controls now inspect actual success values and exact error payloads.
No semantic expectation was weakened. The initial Quint type check rejected
scalar =exclude= arguments; the corrected calls explicitly subtract singleton
sets.
