refined to provider-indexed epochs/cursors after topology review; it is not

subsequent draft used an unavailable tactic. Both elaborations failed; neither
their partially elaborated declarations nor the resulting =sorryAx= diagnostics
were accepted. The corrected proof uses case analysis and the already proven
stale-cut law; it builds with no =sorry= or disabled lint.

did not reject that syntax, but visual inspection showed unintended disconnected
nodes. Labels were quoted, topology/lifecycle layouts made readable and the SVGs
regenerated. Parser/render success is not treated as proof of graph meaning.

thumbnail render was used for visual review, not as a source or runtime SDK.

path: =ProcessLookupError= could bypass =communicate= and leave the child
unreaped. The original failure did not retain a syscall trace, so that path is
not asserted as the uniquely observed OS event. A deterministic new control
forces precisely this race; the shared signal helper tolerates only a missing
owned process group and still requires bounded =wait/communicate=. Other signal
errors propagate. Both the original startup-exit control and the new control
pass. Cleanup keeps three seconds, and a forced cleanup is still a failure.

diagrams exited naturally 0. Four standalone render checks and all nine composed

the new root contributes fourteen / nine respectively. ASCENT passed 23
assertions, historical ORG 90 and fresh Scheme 702. Source and compiled inputs
matched before/after. No forced successful Scheme exit, Case removal, keepalive
or deadline/heap relaxation was used.

This is process-local semantic and consumer evidence, not remote authentication,
