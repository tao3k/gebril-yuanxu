* Focused evidence

[[file:25-controller-installation-trust.org][The installation protocol]] passed nine focused Quint Cases. Its safe finite
model checks trust, one activation, current-root admission and knowledge
retention; reachability controls produce expected counterexamples for never
installed/accepted/revoked. Deliberately unsafe publication, forged-root,
ticket replay, revoked-root consumption and knowledge erasure transitions each
produce an actual TLC counterexample, not a parser failure counted as success.

Ten Context Lean roots build successfully in 81 jobs. The installation root
adds nine theorems and six guards. These conditional laws use LeanPOO Focus;
the private issuer/host trust assumptions are not replaced by Boolean fields
in a Lean structure. Existing dependency linter warnings are not suppressed.

Fresh Scheme replay passed 182 assertions and naturally exited 0, adding 27
installation controls to the prior 155. Positive controls use real ORG
Elements/Contract-derived Context plus the existing Assurance/Core lifecycle
fixture. Negative controls cover forged/copied roots and root proofs, copied
claims/configurations/tickets, absent tickets, denied/withdrawn decisions,
cross-proposal and consumed authorization replay, pending authorization after
root revocation, stale review rejection, obligation reopening and reinitializing
a revoked identity. Another valid root cannot reclaim an owned controller name.
Historical Project knowledge remains present. No effect delivery is invoked.

* Failed attempts retained

The first focused Quint attempt failed parsing because a typed action lacked
its return annotation; the second rejected a reserved built-in action name.
Neither is evidence of a semantic counterexample. Both were corrected before
all nine Cases passed.
