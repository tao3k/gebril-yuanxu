* Ownership and threat

[[file:01-agent-context-lifecycle.org][10.06.43.01]] owns Context; [[file:18-concurrent-registry-session-retirement.org][10.06.43.18]] supplied CAS and retirement ingress.
This extension closes the local consumer-admission gap where a request could
replace the designated source with an unbound or newly issued source after
retirement. Module issuance proves exact local construction, not source approval.
Public Session IDs, matching schemas and copied POO properties are not credentials.

Semantics remain in =Modules/ai-agentic-context=. The optional AITIA Assurance
consumer is downstream; the parent imports no AITIA module. Proofs only
constructs inputs and consumes these Module boundaries. RFC 0015 is a Case.

* Configured binding, not a claimed field

Both =org-context-admission-profile= and the named
=assurance-context-admission-profile= require =authority:= and =governance:=.
The designated source must be an exact issued Session source handle and the
Governance configuration must be a real POO Governance Profile.
The parent binds that tuple privately to the exact verification adapter,
under a configuration mutex. The same adapter cannot be rebound to another
source or Governance referent. Configuration is host-trusted bootstrap,
not an operation available through submitted ORG facts or ASCENT relations.
Issuing a new source alone does not change any existing configured binding.

Profile presentation slots retain those values for inspection, but acceptance
does not trust them. Ordinary POO extension retaining the adapter continues
to work; overriding displayed source/Governance cannot change its private pin.
Changed approved source or Governance requires explicit trusted configuration
with a new adapter and new review, not silent request-side replacement.
This does not authenticate a remote principal or authorize arbitrary bootstrap.

=org-context-consumer-source-current?= atomically checks exact issued source,
current collection/generation and equality to its privately recorded owner.
An unbound collection can still represent structural/history data, but it
cannot be admitted by a configured Session consumer. Raw selection is not
protected disclosure or consumer authority; full unified Query/GQL adaptation
and pre-I/O authorization remain separate obligations.

* Assurance and Governance crossing

Parent admission checks the private source pin and configured Governance
referent before support/review/permission callbacks, then rechecks after them.
Real Governance assessment, Context cut, scope, current Core review and
configured permission are still required. Source authentication does not
replace them, turn eligible into authorized, or issue an effect grant.

The Assurance review operation independently checks the same captured source
and Governance, before and after its Host checks. Calling =yuanxu-verify=
directly with an unbound/foreign-source or copied-Governance request therefore
cannot bypass the consumer wrapper and mint a review. Core retains exact
private adapter/seal issuance. A seal or raw valid-evidence observation alone
is not admission: the current binding is checked again at consumption.

Trusted callbacks and source/adapter bootstrap remain control-plane premises,
not untrusted claim predicates. Remote source provenance, authenticated event
delivery and authorization to perform bootstrap are not implemented here.

* Retirement and target knowledge

Retirement advances all collections attached to the designated source.
Rebuilding with no source, a copied source, or another issued source sharing
the retired Session ID cannot satisfy the original consumer Profile.
Rebuilding against the original retired source also fails membership checks.
Remaining Sessions need fresh collection review; a fresh survivor review passes.

Independent Project knowledge retains its own approved target source and
review premises. The real handoff Case now uses a surviving target Session
and separately configured target source/Profile, rather than representing
knowledge retention as renewed access for the retired producer Session.
No Project storage/disclosure or Session reincarnation is implemented.
