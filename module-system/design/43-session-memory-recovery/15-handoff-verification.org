* Reproduction

Compile the proof consumer into the current ordinary package first, retaining
the caller's installed dependency load path:

#+begin_src sh
gerbil compile -O packages/proofs/context-lifecycle/handoff-controls.ss
#+end_src

From the repository root:

#+begin_src sh
CONTEXT_ASCENT_GERBIL_PATH="$ASCENT_PACKAGE_PATH" \
  CONTEXT_SCHEME_PACKAGE_PATH="$POO_SCHEME_PACKAGE_PATH" \
  python3 packages/proofs/context-lifecycle/verify.py
#+end_src

Focused diagnostics remain distinct from the combined gate:

#+begin_src sh
python3 packages/proofs/context-lifecycle/check_quint.py --model ContextHandoff
#+end_src

The package selectors refer to installed dependencies. No machine-local
absolute path or transient SDK is required by this document.
