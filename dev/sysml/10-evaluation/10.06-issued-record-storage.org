* Responsibility and unchanged boundaries

This follows [[file:10.05-issued-traversal-projection.org][10.05]]. The issuer owns the immutable association between an
original read identity and its captured payload. Core consumes that association;
it neither manufactures reads nor maintains another cache protocol. The selected
read graph, ordered dependency occurrences, observer deliveries and fresh
currentness checks remain unchanged. No passing admission result is cached.

* Producer representation

Use one fixed-arity private closure. A real, RTD-checked record requests the
unchanged authentication checks; =#f= requests detached inspection copies. The
public =object-read-issuance= interface still returns five values and invokes
only the original registry-associated closure. Callers cannot select an alleged
issuer, register a purity flag or acquire signing authority through inspection.

The weak-key/weak-value registry, original read class, exact payload checks,
dependency order, key-shape copy and original closure identity stay intact.
Inspector results copy the payload vector, dependency spine and compound-key
spine. Mutating these copies must not mutate or authenticate a signed record.

The model assumes the native identity projection, RTD guard, private lexical
capture and sequential execution boundary. It does not prove Gambit's closure
layout, GC behavior, arbitrary FFI safety or atomic external-file deployment.

Core consumer, matched retention and full capacity qualification must also pass
before this change can be called an end-to-end capacity repair.

* Remaining storage: private dependency snapshot

The next candidate changes private representation only. Each native record
keeps its original public dependency list, including repeated occurrences. Its
issuer previously copied the same sequence into another pair spine. A private
vector can retain the same identities in order; inspection converts it back to
a detached list. Empty snapshots use a shared empty vector. No public field,
dependency edge, observer call or replay-root policy changes.

=private_sequence_authentication= proves that comparison against the dense
snapshot equals comparison against the original sequence. Inspection recovers
that complete sequence. =IssuerSequence.qnt= checks the finite representation
boundary and supplies expected counterexamples for deduplication, reordering and
aliasing the inspection result. Existing issuer/replay controls still own
forgery, currentness, parent isolation, both requirements and laziness. These
models do not prove vector GC layout or private reflection resistance.
The native loop's bounded index traversal and pointer-to-model identity mapping
remain source-correspondence assumptions, checked by the native repeated-edge
controls; there is no extracted compiler-correctness proof.
