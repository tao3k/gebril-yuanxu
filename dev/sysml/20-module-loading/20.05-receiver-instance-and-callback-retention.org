* Native ownership correspondence

| Retained route | Existing owner | Safe sharing boundary |
|----------------+----------------+-----------------------|
| Read receiver, instance, revision and birth | Native read issuer | Preserve all identities; equal contents are insufficient |
| Instance hash and its cached values | One receiver | Never pool across parent/child receivers |
| Name/index shape | Native slot-layout producer | Already shared through weak shape catalogue; cells remain local |
| Frame/effective argument spine | One Generic invocation | Already the same pointer within one call; do not merge calls |
| Callback captured environment | Its actual closure | Do not infer immutability from equal values or a pure-looking name |
| Compiler context/source catalogue | Existing admitted reader | Role helper references the original catalogue; fresh source checks remain |
| Immutable ordered dependency snapshot | Native producer only | Full ordered identity equality and actual immutability required; Core cannot intern exposed lists |

=slot-layout.ss= already separates shared shapes from receiver-local vectors.
Switching all reads to =.ref/inline= is not a demonstrated memory repair: native
ordinary hashes remain and a layout adds a value vector. The native weak issuance
registry does not by itself strongly retain all records. Prepared source bytes
are also already referenced by pointer in the source-observation table; there is
no evidence here that every reader copies all source strings.

A separate source-level diagnostic defect was found:
=read-module-source-type= swallowed EVERY =file-info= exception into absence.
It now follows the already maintained =role-forms.ss= policy:

#+begin_src scheme
(with-catch
  (lambda (exception)
    (if (no-such-file-or-directory-exception? exception) #f (raise exception)))
  (lambda () (file-info-type (file-info path #f))))
#+end_src

Only genuine absence becomes =#f=. Other native exceptions preserve their
identity/type and cannot be cached as absence by =module-source-observe=.

family. It confirms the native type exception rather than a stale-input error.

historical =std/serde/interface.ssi= refusal. Clean/rebuild recovery alone cannot
establish that exact causal chain, and the original triggering process is gone.
