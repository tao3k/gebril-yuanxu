* Automatic generation and explicit test execution

Native Types own domain membership. =testing/type= derives supported bounded
generators from their actual descriptors; =testing/property/test.check-property=
turns every non-passing report into a standard =std/test= failure. No duplicate
generator registry, property runner, environment opt-in or public test wrapper
is added. Unsupported descriptors refuse rather than falling back to Any.

Importing a module does not execute PBT. The existing native Suite/Fixture is
the execution boundary. Its normal discovery through =init.exports.tests= and
the standard Just/Harness queue executes the added property automatically.
Domain relationships still require an explicit property: a Type alone cannot
infer that two services must agree or that a captured parent plan is stale.
