* Package ownership and absence of old-runtime fallback

The complete producer passes its existing =just build-core= entry with the
unchanged 300-second fence. Runtime build wall time was 145.74 seconds; this is
a qualification observation, not a performance comparison.

The first fresh Core prefix was correctly refused by official package
management because it had no dependency manifest. The source was then linked
and built through =gerbil pkg link --global-env= and =gerbil pkg build= in a
private prefix. No old manifest was copied and no package check was bypassed.
Package version metadata describes its Git base; the source hashes above are
also necessary because the protection deltas are not committed.

An attempted external-library overlay exposed obsolete POO artifacts from the
old installation. Its import failure was retained, and that entire overlay was
removed. Final Core builds/tests resolve POO and Core exclusively in the new
prefix, not by borrowing missing modules from an earlier runtime. The default
Core build compiles all 256 selected library targets through its existing
runtime Make entry. Module loading and build execution remain separate.

Consumers are migrated directly; none of those retired modules is recreated.
The runtime issuer source inventory used by the existing Quint checker follows
the actual =mop.ss= hook owner instead of requiring deleted
=inheritance-hooks.ss=. Lean projection bindings name the actual object source
digest, independently of the still-unchanged release dependency pin.

Role value validation now selects the descriptor's public
=.validation-fields= method with the actual candidate. Core decorates only the
selected field validators to enroll the checked receiver before validation;
runtime ObjectContract still owns field selection, normalization, diagnostics
and final obligations. No second field table is introduced. A regression warms
the parent validator, derives a method through runtime slot refinement, and
checks the real argument, one method invocation and unchanged result identity.

The JSON Schema emission facade no longer copies implementation imports.
The runtime and structural emitter remove their unused inherited dependencies;
the three files delete 70 import/comment lines and add four lines. Existing
export names and implementing owners remain the same. Runtime Schema Types use
=validate=; explicit evidence assertions use the existing =yuanxu-value-admit=
boundary rather than trying to call contextual =.admit= on a plain Type.

* Assurance responsibilities

The existing SysML split is retained: Lean owns representation, identity and
reuse laws; Quint owns observable schedules and refusal counterexamples;
Scheme gates own actual MOP construction, normalization, callback behavior,
runtime issuance and source currentness. No parallel PBT runner, new formal
semantics or duplicate proof project is added. Updating a source digest alone
does not establish runtime acceptance or callback purity.

Runtime qualification uses the upstream default =just test-file= entry,
including its original 1 GiB/90-second limits. Core uses its default
=just test-file= entry, 2 GiB/600-second/60-second-idle limits, serially.
The scopes remain explicit: focused runtime qualification is not whole-suite
CI, ten-thousand-module acceptance or a publishable dependency closure.
