SDK reference as another SDK allocation? This follows [[file:20.09-fixture-compiler-budget.org][20.09]]. SysML

to existing ReadRetention QNT controls, and source correspondence to Scheme.
No second temporal model or Core cache protocol is introduced.

The signature census hashes primitive identity codes and compares code plus
ALL captures with =eq?= on collisions; it never calls a thunk. Repeated capture
signatures do not authorize merging function identities: =compute-slot= can
observe the standard function. Likewise, the 297 invocation frames already
share their effective-method argument spines; there are zero independent
argument spines in that measured set. Neither is a new sharing repair.

Singleton-vector counting inspects the registered issuer closure, excludes the
candidate value, requires a vector of length one containing the sole original
dependency, and deduplicates the vector identity. Inspector-created snapshot
copies are not counted as retained issuer storage. The bound native source
confirms the captured vector is =parent-copy=; this is a source correspondence,
not a compiler-independent introspection theorem.

* Narrow producer repair

The native =object-record-read= keeps a single non-vector parent identity
directly. Empty and multiple-parent snapshots remain vectors. A vector-valued
singleton also takes the dense fallback, making the private variants disjoint.
The public list is unchanged. Inspection still allocates a fresh list; callers
cannot mutate issuer authority through that copy. Authentication still compares
all original identities in order, including repeated occurrences.

This removes a private wrapper allocation only. It does not remove a read,
edge, receiver, observer callback or authentication pass. Receiver instances,
revisions, callback environments and successful admission results are not pooled.
No receiver state is shared because it happens to have equal values.

* Structural and temporal evidence

=PayloadSharing.snapshotParentsExact= proves exact restoration of the identity
sequence. =snapshotAcceptsExactlyOriginal= preserves the acceptance predicate;
=snapshotPreservesEveryOccurrence= preserves every position, not merely a set.
The finite model does not prove the compiler's capture layout or GC ownership.
The vector-valued fallback is checked by source correspondence, with native
mutation/copy-isolation tests closing the executed non-vector read path.

Existing ReadRetention QNT qualification passes seven matched cases, including
negative controls for receiver-only deduplication, omitted transient reads,
cached approval, dropping the second requirement and eager unselected demand.
These are temporal controls, not proof that a compiled Scheme edit implements
the model. Native issuance tests and real Scenario regressions remain required.
