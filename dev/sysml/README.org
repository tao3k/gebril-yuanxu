does not relocate or duplicate them.

* One formal owner per question

| Question | Primary owner | Reuse instead of duplication |
|----------+---------------+------------------------------|
| Which immutable structures may share storage without changing lookup, identities or ordered edges? | Lean / LeanPoo | =PayloadSharing.lean=; no matching QNT copy |
| Can callbacks, invalidation, recovery or event ordering admit a stale value? | QNT | Existing =IssuedRootForwarding=, =ReadRetention= and =IncrementalRoles= transitions |
| Does the actual MOP preserve the modeled relation? | Scheme consumer regression | Existing Just/Harness controls |
| What is retained or allocated? | Bounded runtime measurement | GC accounts plus classified identity-union census |

SysML allocates these claims and assumptions; it does not prove them. A
workstream may have only a Lean owner or only a QNT owner. Shared premises
are linked, not reimplemented. The duplicate =PayloadSharing= QNT family
and its runner/digest bindings have been removed; historical receipts remain
historical, not current qualification requirements.

* Required trace for each workstream

| Question | Required artifact | What it cannot establish alone |
|----------+-------------------+--------------------------------|
| What is the system boundary? | SysML structure, actions and requirements | Executable correctness |
| What sequence must fail? | Existing QNT owner and matched negative trace | Unbounded correctness or filesystem trust |
| What property is preserved? | Lean statement, premises and Scheme projection | Runtime behavior without correspondence |
| Does current code implement it? | Source entry + focused Just regression | Untested executions |
| Is it more efficient? | Same workload, cold/hot action and time counts | Stable speedup from a single run |

Every row has an evidence status: design, modeled, machine-checked or runtime
observed. Status is per property, not a blanket badge for an entire workstream.
Model files do not carry trusted currentness results into runtime.
