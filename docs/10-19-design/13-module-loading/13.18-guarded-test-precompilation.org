* Current boundary

The runtime precompilation/=.run= facade described in the topic modules is
retired. Ordinary =t/= inputs go directly to the installed Gerbil test tool;
it owns directory and Suite discovery. =tests.compile=, =tests.run= and
=tests.for-directory= are removed, along with the product batch driver.
Build specifications and issuance remain at the independent build entry.
See [[file:13.28-managed-dependency-and-activation-policy.org][13.28]] for the current ownership boundary.

These modules retain the superseded experiment and its evidence; they do
not define supported APIs or qualify the current implementation.
