* Ownership clarification: a public library does not depend on Core

This is the historical isolated-proposal record. See
[[file:12.06-public-object-contract-implementation.org][the subsequent public-library implementation]] for the local gerbil-poo module
and the qualification's switch from copied generic definitions to its public API.

gerbil-poo is a public library. Its Type, object contracts, diagnostics, checked
invocation and reuse mechanisms must work without Agentic AI Lab. In these documents
"Core consumer" means the yuanxu repository, not Gerbil's compiler,
runtime or standard library. Gerbil's own core/contract APIs are language tools,
not the owner of Agentic AI Lab module/source admission policy.

The public structural contract proposal is tested independently. Schema
adaptation is a consumer/library layered on that protocol. A separate existing
Core admission consumer is included only to check how its receipts behave; it
is not a requirement for using gerbil-poo and introduces no upstream dependency
on Core. Module Graph/source publication policy stays outside the public library.

* Results and evidence boundary

The two contract suites contain 17 cases in total: seven public-library cases
and ten Schema/consumer cases. Both reported MODULE-OK, HARNESS-OK and final OK,
with no error-case/check/harness/module, heap-overflow or stack-overflow marker.
The separate native preparation test also passed. Raw transcripts remain local
temporary artifacts and are not committed.

The main correctness assertions include:

#+begin_src scheme
;; Parent consumer was forced before the child override.
(check-equal? (.get Parent resources web instance_type) "t3.small")
(check-equal? (.get child resources web instance_type) "t3.medium")

;; Existing Core .admit is exercised by the private document adapter.
(check-equal? (configuration-evidence-current? parent-evidence child-snapshot) #f)
(check-equal? (configuration-evidence-current? child-evidence child-snapshot) #t)
(check-equal? (eq? (.get child-evidence candidate) child-value) #t)
#+end_src

Here the generation stamps, selected Graph and snapshot are explicitly constructed
fixture values. Evidence invalidation means that the tested consumer predicate
refuses an old receipt for those new inputs; no background cache purge occurs.
The receipt does not become authentic because its shape matches. Automatic
source capture, complete dependency manifests, association preservation and
consumer authority are still unqualified integration requirements.

* A failed control improved the example

The first resource-cache fixture used an inner name: name expression, which
shadowed the intended outer slot and raised CyclicSlot. It was corrected to a
differently named output slot. This confirms why lexical slot examples must
respect ordinary shadowing; the correction did not replace native receiver
semantics with manually extracted parent values. Early preparation attempts
also exposed an invalid SDK import spelling; the final preparation uses the
normal Gerbil core prelude and passes its native test.

* What is existing, private, or still missing?

Existing upstream: Type validation, POO object/slot inheritance, receiver-local
computation, PR Predicate/typed and checked invocation. Existing consumer:
JSON Schema normalization/validation and Core classification/admission receipts.

Private validated proposal: diagnostic Type wrapping, structural ObjectContract,
Schema/projection adapters, this bounded AWS factory and the document's explicit
snapshot-binding adapter. These definitions live only in generated test modules;
they have not been published in gerbil-poo or installed as Core module APIs.

Still missing: upstream API review, optional/default schema policy completeness,
clean Schema library dependencies, real provider-input conversion, automatic
publication/derivation association, production current-snapshot construction,
dynamic selected-child discovery and corresponding formal/consumer qualification.
No Lean theorem was added or discharged by these tests. No module adaptation,
runtime Loader, live cloud call or push was performed.
