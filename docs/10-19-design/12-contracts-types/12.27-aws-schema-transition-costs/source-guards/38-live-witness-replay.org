* Actual continuation after the 614-publication refusal

[[file:37-prototype-query-import-boundary.org][The previous thousand-declaration gate]] stopped after 614 completed
publications. Its last observations show linear private-context ownership and
375 physical reads per completed publication, but significant metadata replay
CPU. Counts alone do not identify exclusive retained bytes or prove that those
contexts can be released. Their bindings may still be needed by later imports
and deferred Build roles. This change does not clear SDK state or bindings.

The real call chain is =read-candidate -> current! ->
publication-metadata-current -> publication-read-current ->
replay-slot-reads! -> owned-call current? -> weak-reads-current?=.
The last function used to start a separate native DFS for each live owned
receiver. Frame, EffectiveMethod and evidence witnesses can share the same
Generic, Contract and policy suffix. Each independent DFS revisited that suffix
and allocated its own temporary traversal set.

* One check owns the complete live witness set

The closed call's existing weak witness table remains unchanged. At each
currentness demand the implementation:

1. Resolves every still-live receiver and all its original read tokens. A
   missing token for a live receiver refuses immediately.
2. Verifies that each resolved token has that receiver identity. The native
   token structure holds its receiver strongly, so these roots themselves pin
   every resolved receiver. There is no additional receiver list. This does
   not resurrect a collected receiver or suppress a missing-token error.
3. Calls the original public =replay-slot-reads!= once on the combined roots.
   Native token identity deduplication and the native final recheck cover the
   whole set, including shared dependencies.
4. Releases the local roots on return or exception. Nothing stores a successful
   validity decision. Native receiver edges, not a duplicated pin collection,
   provide liveness during the replay.

This changes the scope of an existing native DFS. It adds no cache, read-token
registry, second Graph, reconstructed token predicate or user interface. All
original read observations at construction still occur. The returned receipt
and policy identities are unchanged. A later demand performs a fresh replay.

For R live witnesses with private suffixes A_i and one shared suffix S, the
old nested traversal component is proportional to sum_i(|A_i| + |S|). The
single native DFS visits the union of those original tokens instead. Native
first/final passes multiply both costs by the same constant. In particular,
repeating S R times is removed, rather than merely deleting one check from
every witness. Root collection is still linear in the number of recorded
roots, and every independent admission demand still repeats its checks.
This bound is about token identities in one closed call, not all filesystem
reads, SDK contexts or total work for N Modules.

Unknown methods, Context/obligation callbacks, MOP hooks and borrowed copies
still select =owned-call/full= and keep complete strong support. Their callback
guards are not coalesced. Nor are the reader's separate preparation/admission/
preparation source boundaries merged: no general purity certificate for an
arbitrary token-currentness callback is inferred from an import path. The
batch's correspondence premise is the existing closed, constructor-owned
projection with native currentness queries. Arbitrary callback invocation
counts or scheduling are not an equivalence claim.

weak-witness DFS work; its unchanged value does not mean the removed nested

bytes are 27680 higher. The change removes repeated temporary traversals; it
does not prove that private role contexts are disposable. Allocation-counter
validity differs between runs, so allocation deltas are not compared. The
thousand-declaration result must be reported separately rather than inferred
from the probe or CPU component. The final code removes the duplicate pin list
using the native token-to-receiver edge; its GC control and scale results must
not be attributed to this intermediate pair.
