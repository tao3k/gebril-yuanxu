* A different duplicate in that same chain

Selected publication assembly calls selected-index before constructing its
complete Context. The normal index reader guards sources before reading author
contribution declarations. The AWS selection has no such declarations: its
native Graph nodes, kinds, publications and Core values have already been
demanded by selection/build preparation and the publication entry.

The private index constructor now inspects those existing values with the
public .ref/cached operation. A miss immediately declines the shortcut; it does
not force the missing slot value. If a Core has a contributions slot, even a
cold or empty declaration, it also declines the shortcut. The ordinary guarded
index reader remains responsible for demanding and validating that declaration.

A fully observed route-free index records the same node/publication/Core
revisions as the ordinary reader. It uses the EXISTING weak Graph-keyed index
table. Later empty-index lookups inspect that private completed index and check
its observations; nonempty indexes retain the source guard. There is no second
Graph, namespace tree, source-currentness cache or exported method.

#+begin_src scheme
(def (cached-route-free-index graph)
  (let/cc unavailable
    (def (cached receiver slot)
      (unless (object? receiver) (unavailable #f))
      (.ref/cached receiver slot (lambda () (unavailable #f))))
    (def revision (object-revision graph))
    (def observations '())
    (for-each
      (lambda (node)
        (when (eq? (cached node 'kind) 'module-core)
          (let* ((publication (cached node 'publication))
                 (core (cached publication 'core)))
            ;; Presence inspection does not demand the declaration's value.
            (when (.slot? core 'contributions) (unavailable #f))
            (set! observations
              (append (map observe (list node publication core)) observations)))))
      (cached graph 'nodes))
    (.cc (.o) revision: revision routes: (make-hash-table-eq)
         observations: observations)))
#+end_src

The executable owner, including the existing index observation helpers, is
[[file:../../../../../admission/contributions.ss][contributions.ss]]. It is not a new user configuration surface. The path
assumes the platform's prepared selected/build Graph, not arbitrary unprepared
foreign objects or a claim that cache presence proves source currentness.

* The next source boundary must remain before author metadata

Deleting the index's source traversal alone is insufficient. A late export
getter can change sources before the binder reads a cold Contract handler.
An isolated candidate that left Context collection after that handler fails
the new control: the handler runs once when it must not run at all.

For zero incoming rows the binder now demands its existing base Context
immediately after native index inspection. That Context's source-entry check
validates compiler AND request/configuration observations before cold Contract
metadata/handlers. Its read window ends before Schema getters. The final full
Context check still validates Graph, Schema, Contract revisions and contribution
coverage before publication escape. Nonempty incoming collections retain their
original preparation, export traversal and final checks.

#+begin_src scheme
(def index (selected-index selection graph))
(def edges (incoming index owner name))
(def source-base (and (null? edges) (.get publication context)))
;; Read/register the actual Contract and its handlers only after that boundary.
;; Collect real incoming rows with their existing guarded path.
(def base (or source-base (.get publication context)))
;; Build derived Context, then perform its unchanged complete return check.
#+end_src
