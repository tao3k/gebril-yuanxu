* Question and implementation boundary

The remaining principal role-byte cost is =6N^2 + 2N=. The next proposed fusion
is the reader's =declaration-after= guard followed by
=admit-module-publication!= and =publication-admitted=. This note audits that
actual interval. It does not relabel a publication receiver as checked metadata
and does not claim a further read reduction.

The native reader returns the value of the interface binding. It does NOT
return a =ModulePublicationContract= admission receipt. A successful source
and authoring check establishes different facts from a successful value check.
The current declaration macro preserves native lazy slots. Neither its literal
=.o= syntax nor the maintained name of the predicate certifies getter purity.

* Actual call chain and support

| Owner | Actual work | Effect boundary |
|-------+-------------+-----------------|

| [[file:../../../../../types.ss][Unified producer]] | Normalize the value if requested, classify, admit responsibilities, execute local and Context obligations, create evidence | Normalizers, classifiers, children and obligations are extensible |
| [[file:../../../../../module-system/source/link.ss][Linker]] | Allocate the constant source/publication/evidence record, run publication-admitted, then insert it | No Graph insertion before the tail guard succeeds |

The source owner comparison and private table insertion are closed continuations
only AFTER their inputs have been obtained without further callback execution.
This does not make the preceding producer closed. Public accepted evidence
binds the actual Contract/candidate/Context; it does not independently certify
source currentness at a later publication boundary.

Native =.ref/cached= is not a purity oracle either: it still participates in
read demand and observer delivery. Cached values, active observation and
unknown MOP/Context callbacks must not be conflated with a callback-free
continuation. The existing read-window cache cannot span these effects.

The first test attempt used a value override for a previously undeclared
Context method. Native slot presence correctly did not treat that as a declared
method; the callback-count assertion failed. The final fixture declares the
method through native object inheritance and asserts presence before admission.
This test correction is not a production change to slot or Contract semantics.

Before the next source sweep can be removed, the real producer must supply
the following native correspondence, without a contributor-supplied pure flag:

1. The actual normalized subject and actual Contract reference are the ones
   consumed by the continuation, including any contextual child admissions.
2. Every getter, normalizer, policy method, Context obligation and observation
   callback in that interval is either completed before the guard or remains
   behind an independent full guard. Descriptor names and warm cache state
   cannot substitute for this audit.
3. Parent/prototype revisions, source support and Context support remain the
   same; mutations including edit-and-restore invalidate the handoff.
4. The evidence/record continuation does not escape into a later operation or
   authorize reuse across a native import, initializer or open callback.

Moving .admit into the reader without establishing these facts merely moves
the effect boundary. Adding the necessary guard back before an open callback
does not reduce =6N^2 + 2N=. This round therefore preserves the production
guards rather than publishing an unsafe lower recurrence. Dependency-closed
admission remains an implementation gap, not a completed performance claim.
