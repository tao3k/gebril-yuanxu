This section belongs to Core design. Domain libraries own AWS/Kubernetes/CI/CD
vocabularies. Generic object mechanisms can live upstream in gerbil-poo while
remaining available through the same integrated Module System to authors.

Do not add =Native= to new Contract, object, module or file names. Existing
identifiers containing that word are cited only to locate current code; this
design does not rename implementation symbols or add compatibility aliases.
