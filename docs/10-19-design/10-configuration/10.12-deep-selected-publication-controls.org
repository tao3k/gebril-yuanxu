* Demand every path receiver, not every export

The exercised path is scope.exports.policy.requirements.port. The collector
records a revision BEFORE each .ref and separately records the final payload:

#+begin_src scheme
(def (walk-export scope path)
  (unless (and (pair? path) (list? path) (every symbol? path))
    (error "invalid deep export path" path))
  (def observations '())
  (def payload
    (foldl
      (lambda (name receiver)
        (unless (and (object? receiver) (.slot? receiver name))
          (error "unresolved deep export" path name))
        (set! observations (cons (observe receiver) observations))
        (.ref receiver name))
      scope path))
  (values payload observations))
#+end_src

The test checks the four observed receiver IDENTITIES, not just observation
count: scope, exports, policy and requirements (stored in reverse walk order).
There is no .all-slots walk of domain exports. A sibling requirements.cold would
increment a Probe vector and raise if demanded; its counter remains zero after
collection, coverage, admission, preview and the applicable refusal controls.
Reading that Probe is a test observation, not a user-visible cache/evidence API.

The collector gets each record through the REAL .selected-record and checks its
publication against the actual selected node. Coverage reuses .selected-record,
checks the exact record/SourceRef/publication/generation/key/path association and
re-walks the deep path to compare final payload identity. Missing and substituted
rows are refused. Public .for-export resolves the application's actual Contract;
the test derives that descriptor to attach the bounded joint policy obligation.
It does not replace the native .admit producer or production .publish.

Selected node/publication/core/contributions-container revisions are captured
before route enumeration. This is necessary even when the later payload walk is
correct: deleting a route after indexing must not silently remove an obligation.
The metadata baseline and every path/payload/origin observation join the same
currentness fence, along with each REAL prepared source's admit-current guard.

| Control | Result |
|---------+--------|
| Deep origin resolution | Two collected rows, exact .selected-record identities, accepted production scope evidence, four exact receiver observations per path |
| Intermediate edit | .put! on requirements.port writes the SAME leaf back; leaf identity/value stay unchanged, but publication refuses with underlying Error-message deep export receiver changed |

| Actual source edit | Edit operations/config.ss after assembly; a valid 5433 child refuses with the specific underlying stale prepared Module publication error |
| Parent cache and final preview | Force both parent leaves at 5432 BEFORE creating Release; checked publication admits a 5433/5433 child and binds evidence.candidate to next; cached parent stays 5432; explicitly attaching its old plan to the child refuses |

The valid child in the source-edit control matters: using only the unmodified
5432 parent would already violate policy and could mask a broken source guard.
The intermediate-edit control similarly avoids relying on a changed port value.
No assertion is satisfied merely by observing some unrelated exception.

Every applicable control checks the cold sibling Probe and absence of
fixture/unused from the selected module order. The malformed disabled interface
would fail if the reader parsed it. This establishes no evaluation/linking of that
module, not zero directory discovery/stat calls. Core requires dependencies of a
demanded module are still eagerly linked by existing link.ss; this test does not
claim per-export dependency injection or catalogue-wide cost guarantees.

* Remaining production boundary and Reflection

The metadata query, collector, coverage checks, receiver observations and binding
of contributions into the descriptor/Context remain TEST-LOCAL. The query scans
selected metadata once for this small control; it is not the generation-cached
production route index proposed in 10.10. It covers selected Core declarations,
not Feature contribution projection, dynamic method sources or arbitrary IO.
Raw mutation of private lists/strings and untracked external state remain outside
native MOP revision guarantees. SourceRefs are actual admitted local endpoints,
not cryptographic authentication of remote contributors.

The result closes two fixture gaps: selected record provenance no longer comes
from manually assembled records, and a deep export no longer has a top-scope-only
revision fence. It does not justify a new configuration syntax or expose internal
records to users. The next integration review must preserve these refusal and
laziness controls when installing the production adapter, qualify the then-current
linker, and measure selected-graph cost separately from domain payload demand.
