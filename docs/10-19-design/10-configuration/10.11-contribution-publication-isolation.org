| Control | Required result |
|---------+-----------------|
| Operations=5433, Security=5440 | Native .admit refuses; obligation constraints retain BOTH ordered diagnostic origins and values; .publish preserves supplied previous subject |

| Cached parent plan explicitly attached to child | Connection/plan classifier refuses stale projection |
| Final Gitea port 6000 versus server 5433 | Final connection classifier refuses |

A source preparation refusal and a policy obligation refusal are different
boundaries. The latter returns Core evidence; errors inside checked .publish
become publication failures. The caller's previous subject is retained, not
newly re-admitted or certified current under the changed source/policy.

* Failures retained during development

1. Core's unconfigured local test path could not resolve :clan/poo/object.
   A separate verified pinned source path fixed test discovery; no global install
   or runtime compatibility implementation was substituted.
2. The first fixture used an unavailable :std/srfi/1 path; it now uses the
   runtime's :std/list/list library.
3. Duplicate fixture compiler identities were correctly refused by the REAL
   build graph; each owner now has its own compiler identity.
4. =record: record= in .o raised native CyclicSlot: the slot binding shadows
   the outer name. This exposed a real flaw in the previous 10.10 design snippets.
   Metadata capture names were corrected there; the fixture uses ordinary native
   constructor arguments for captured metadata. MOP is not a substitute for
   checking the actual declaration semantics.
5. A mechanical constructor edit incorrectly moved =>.+ outside declaration
   syntax and was rejected during expansion; receiver refinements were restored.
6. A root-directory invocation used the wrong test path and did not run controls.
7. The old Gambit error-exception? predicate did not recognize Gerbil Error.
   Negative controls now check Error? AND the expected Error-message. This retains
   the actual refusal rather than loosening the test to accept any exception.
