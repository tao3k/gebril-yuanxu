* Organization and reading order

Each platform owns an independent directory and an Org dossier. The dossier
owns its configuration model, source evidence, issue observations, reflection
and conclusions. A cross-platform synthesis must cite these owners instead of
reducing several platforms to paragraphs in one mixed research document.

Start with [[file:../30-39-research-foundations/30-method/30.01-evidence-protocol.org][the research and evidence protocol]]. The current dossiers are initial
source-reading notes with explicit gaps, not completed independent experiments.

| Subject | Independent owner | Particular research boundary |
|---------+-------------------+------------------------------|
| Terraform | [[file:23-terraform/23.01-index.org][Terraform research]] | HCL-based inputs, module interfaces, lifecycle and planning phases |
| OpenTofu | [[file:24-opentofu/24.01-index.org][OpenTofu research]] | Stable instance identity, providers, state and version-specific behavior |

Related languages, libraries and ecosystems are recorded in the appropriate
dossier but are not conflated with the platform. HCL toolkit semantics are not
identical to Terraform restrictions; Nix is not identical to the NixOS module
library; Omnibus is an ecosystem use of Nickel rather than Nickel itself.
When a language/ecosystem requires substantial independent analysis, give it
its own dossier and link the platform to it. Do not force a new subject into an
unrelated directory merely to keep the list short.
