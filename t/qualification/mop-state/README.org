=snapshot.ss= is a private consumer test helper. It reads actual native records
and raw selected prototype metadata; it never implements object evaluation,
source admission, a Loader, or a production byte cache. Runtime class/field
reflection is from the installed Gerbil MOP. Producer APIs and the recorded
checker are bound to the installed gerbil-poo package identity.

The native source-observer parameter is read, not replaced by a testing purity
flag. Unknown checkers are not invoked. Raw metadata comparisons use =eq?=
reference identity. Numeric values/revisions are not substituted for object
identity; equal separately allocated numbers exercise that distinction.

The Gitea/PostgreSQL tests use existing resource-owning fixtures, actual JSON,
reader/link/publication and public =.admit=. Temporary source trees isolate
intentional source mutations. No shared installed dependency or production
Scheme source is edited. Some tests deliberately clear or corrupt a private
receiver's native cache; they are negative controls, not user extension APIs.

MOP snapshot equality covers the selected recorded footprint only. It is not
source currentness, a concurrency transaction, a history certificate or an
untrusted-code sandbox. See
[[file:../../../docs/30-39-research-foundations/32-module-assurance/32.23-mop-state-extraction.org][32.23]] for exact evidence and open correspondence premises.

* Constrained return-tail qualification

[[file:../../../docs/30-39-research-foundations/32-module-assurance/32.29-constrained-return-tail.org][32.29]] separates a replaceable caller wrapper from a temporary producer-owned
source-event gate. Opaque observers are refused before invocation; this is not
a purity declaration or a production fix. An independent writer remains a
correct-model limitation requiring snapshot/conditional-commit authority.

The final candidate covers both slot-replay (including cache exit) and
return-currentness. A return-only gate is retained as an unsafe matched control.
Only source-observer calls are restricted; arbitrary MOP record/checker ownership
and external snapshot/commit remain separate premises.
